## Our Commitment

Metups is committed to ensuring the platform is accessible to all users, including those with disabilities. We aim to meet **WCAG 2.1 Level AA** standards.

## Implemented Accessibility Features

- [ ] Semantic HTML5 elements (nav, main, header, article)
- [ ] ARIA labels on icon-only buttons
- [ ] Viewport meta tag with proper scaling
- [ ] Touch targets minimum 44×44px on mobile
- [ ] Font sizes using relative units (rem)
- [ ] Focus indicators on interactive elements
- [ ] Colour is not the sole means of conveying information
